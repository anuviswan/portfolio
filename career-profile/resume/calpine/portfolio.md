# Overview

Calpine Group marked the beginning of my professional journey in scientific software engineering. Over nearly a decade, I progressed from Junior Software Developer to Principal Technical Lead while contributing to software platforms used in pharmaceutical laboratories around the world.

My work focused on building reliable software for laboratory automation and scientific instrumentation, while gradually taking on broader responsibilities in technical leadership, architecture discussions and offshore engineering coordination.

# Highlights

- Progressed through five technical roles over nearly a decade.

- Worked across multiple scientific software products supporting pharmaceutical and biotechnology laboratories.
